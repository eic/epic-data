# Dihadron benchmark: theory correlation functions

`Cth_ep.root`, `Cth_eAu.root`, `Cth_eAg.root`: CGC theory correlation functions
C_th(Q², x, z₁, z₂, Δφ) as 5-dimensional `THnSparseD` grids, one per collision
system. The dihadron benchmark of
[eic/physics_benchmarks](https://github.com/eic/physics_benchmarks)
(`benchmarks/SIDIS/dihadron`) weights the gluon-initiated channels with
Cth_eA / Cth_ep, interpolated at each hadron pair.

The files are stored with Git LFS (`.gitattributes` covers this directory
only), and are unchanged copies of those used by the original analysis,
rahmans1/DihadronAnalysis at c36b8c6.
